## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability in this project, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to **soundfury37@gmail.com**.

You should receive a response within 48 hours. We ask that you verify the vulnerability before reporting it and provide as much information as possible to help us reproduce the issue.
