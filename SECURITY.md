# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you find any security vulnerability, please report it to us as soon as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to **soundfury37@gmail.com**.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

## Response

You should expect to receive a response within 48 hours. We will keep you updated on our progress as we investigate and fix the issue.

## Scope

This policy applies to all files in this repository.
