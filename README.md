# Project Palette

## Overview
This repository is the home for Palette's UX experiments and improvements.

## UX & Accessibility Standards
We strive to make our applications accessible to everyone.

### Principles
- **Semantic HTML**: Use the right tag for the job.
- **ARIA**: Augment HTML when native semantics aren't enough, but don't overuse it.
- **Keyboard Navigation**: Everything must be operable with a keyboard.
- **Focus Management**: Focus states should be visible and logical.

### Tooling
We use ESLint with `eslint-plugin-jsx-a11y` to enforce accessibility rules automatically.
